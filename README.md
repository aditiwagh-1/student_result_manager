# 🎓 Student Result Management System (Python)

A simple console-based Python project to manage student records, including adding students, viewing all students, and checking results.

---

## 📌 Features

- Add new student with marks
- View all stored students
- Check individual student result
- Simple menu-driven interface
- Stores data in memory using Python dictionary

---

## 🛠️ Technologies Used

- Python 
- Basic concepts: loops, dictionaries, conditionals, input/output

---

## 🚀 How to Run the Project

1. Install Python (if not installed)
2. Download or clone this repository
3. Run the script:

```bash
python student_result_manager.py


📋 Menu Options
When you run the program, you will see:
1. Add Student
2. View All Students
3. Check Result
4. Exit

✏️ How It Works

1. Add Student
Enter student name
Enter student marks
Data is stored in a dictionary

2. View Students
Displays all stored students with marks

3. Check Result
Enter student name
Shows marks and pass/fail status

4. Exit
Stops the program
